# Project Record Builder

Over the years, while working as a structural engineer, my project folders have grown into a mess.

Different naming conventions, inconsistent folder structures, projects inside
other projects. Usually it's client/project, but not always. Years of old work
I want to properly go back through and document.

This project is meant to help me build a structured backlog of my projects.
The idea is to create a record for each project, give it a standard name like
`2018-021_KAUST_SWIMMING-POOL-CANOPY`, keep the useful information together,
and make the whole collection searchable.

## Why I'm building it

This is also a project for learning web development. I'm using it to sharpen
my HTML, CSS and JavaScript, and to get comfortable with the browser APIs I'll
need along the way.

I'm intentionally writing the code line by line from scratch, without Copilot
or AI-generated code. I could build something like this much faster with AI,
but the point here is to understand how it works and get better at building it
myself.

## Planned features

Some things I want to build. The list will change as I go.

- Project records with client, contacts, dates, location, scope, status
- Technical info: structure types, software, metrics, costs, fees
- Standard project naming
- Searchable table and basic stats
- Import / export
- Local files I can back up or move

## Current status

Very early. Right now I'm just building the UI — header, panels, the shape of
the form. Nothing saves yet.
